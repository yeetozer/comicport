# ComicPort Privacy Policy

Last updated: September 10, 2026

ComicPort is designed as a local-first comic reader.

## Data collection

ComicPort does not operate an analytics, advertising, account, or tracking service.
The app is designed not to send your comic files, reading history, notes, OCR text,
ratings, favorites, or library information to ComicPort servers.

## Local processing

Comic files are imported from locations you choose. Reading, cover generation,
metadata processing, OCR, search indexing, recommendations, statistics, notes,
and library organization are processed locally on your device.

## Source folders

If you choose a Source folder, ComicPort stores a security-scoped bookmark so it
can access that folder again. This permission is stored locally on the device.

## Sync Folder

ComicPort Sync Folder is optional. If enabled, ComicPort writes a small reading-state
file to a folder you explicitly choose. ComicPort does not run a sync server.

If you choose a folder managed by iCloud Drive, Dropbox, OneDrive, or another
storage provider, that provider and the operating system may transfer the selected
folder according to their own privacy policies.

ComicPort Sync does not copy the comic-book files themselves.

## Apple system services

Some optional features may use Apple-provided on-device or system services, such as
text recognition, speech, and translation. Translation language resources may require
a system-managed download.

## Third-party libraries

ComicPort uses libarchive technology to read supported archive formats. It is used
for local file processing and is not used for analytics or advertising.

## Tracking

ComicPort does not track users across apps or websites.
