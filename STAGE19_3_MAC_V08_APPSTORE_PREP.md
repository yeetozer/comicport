# ComicPort — Stage 19.3 / Mac v0.8 — App Store Preparation

This stage does not add a large end-user feature. It prepares the release candidate
for App Store work.

Included:
- PrivacyInfo.xcprivacy in the main app Resources target
- Books category in Info.plist
- encryption-export declaration retained as false
- App Store metadata drafts (English + Turkish)
- App Privacy answer draft
- public privacy-policy draft
- App Review notes
- screenshot plan
- content-rights checklist
- submission steps
- release blockers / account-specific decisions

The production Bundle ID and Apple Developer Team are intentionally unchanged.
Those values belong to the developer's Apple account and should be set immediately
before the first production Archive.

WidgetKit remains paused.
